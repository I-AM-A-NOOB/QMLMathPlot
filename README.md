 隐函数方案怎么做才能"完美"——两块拼图

 你记的没错，就是隐函数（逐像素 signed-distance）。之前那版只有第一块：

 ① 屏幕空间距离描边（原来就有）：每个像素算它到曲线的一阶距离

 ```glsl
slope = f'(x)·(像素/世界y)/(像素/世界x);
d = |f(x) − y| · (像素/世界y) / sqrt(1 + slope²);
cov = clamp(lineWidth/2 + 0.5 − d, 0, 1);
 ```

 好处：任何斜率都等宽、天然抗锯齿、极点/跳变都自动正确（tan(x) 我验证过：干净的双曲线分支，没有误填）。

 ② 欠采样包络带（原来缺的，也是 sin(1/x) 难看的根因）：当一个像素的 x 区间里塞进了多个振荡（局部周期 < 1
 像素）时，逐像素距离已经没有意义——最近的那条分支是伪随机的，画出来就是摩尔纹/随机锯齿。此时应该把该列的 [min, max]
 填成实心带；对 sin(1/x) 这恰好等于填它的真实 ±1 包络。

 判据（两把互补的尺子，取并集，都在同一个像素内用 8 个采样点算）：

- 列内折返次数 ≥ 2：曲线在这一列里上下折返两次以上 ⇒ 一列塞进多个振荡；（只折返 1 次 =
  可分辨的极值，照常画线——这一条把 sin(x) 的峰、tan 的极点都正确排除在外）
- 实测跨度 ≪ 导数预期 |f'|·dx：振荡快到 8 个采样都抓不住规律时兜底（深缩放靠它）
- 两道闸门：跨度 < 1.5 像素不填（避免把峰顶的微小起伏填成色块）、跨度 > 4×视口高不填（避免把极点填满整列）

  │ 我调试中踩的两个坑，记下来免得再犯：① 一开始用"实测跨度/线性预期"当判据，结果 sin(1/x) 导数极大、比值趋近
  │ 0，包络被关掉（只剩几根孤立竖条）；② 4 点采样的"全变差/跨度"对随机相位正弦平均只有
  │ ~1.06，够不到阈值。换成上面的"折返次数 + 导数兜底 + 8 点"才稳。
